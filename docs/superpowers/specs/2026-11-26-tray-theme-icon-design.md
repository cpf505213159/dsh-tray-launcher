# 托盘图标与菜单：主题自适应美化

日期：2026-11-26
状态：待批准

## 意图

托盘图标在深色任务栏上不可见（黑色鲸鱼 + 黑色背景）。目标是让图标和右键菜单都跟随
Windows 主题自动切换配色，并去掉梁祖、鲸鱼娘两个预设图标，只保留可自适应的 DeepSeek
鲸鱼与自定义图标。

## 目标

- 深色任务栏 → 白色鲸鱼；浅色任务栏 → 黑色鲸鱼；主题切换后无需重启托盘。
- 右键菜单配色跟随主题，加入图标、行距与悬停高亮，观感更精致。
- 删除梁祖、鲸鱼娘资源；菜单只保留「自动适配主题」与「选择自定义图标…」。
- 顺带修复体检发现的问题（硬编码 liangzu 图标、切换图标弹气泡、改写快捷方式图标等）。

## 非目标

- 不改变启动/重启/浏览器打开逻辑。
- 不引入第三方二进制依赖或下载资源。

## 约束

- 纯 PowerShell 5.1 + WinForms，BOM 必须保留。
- 托盘常驻内存不能明显上升；主题检测不能用重模块或阻塞 UI。
- 不能破坏「外部 harness 挂载」与「自定义图标」两条现有路径。

## 方案

### 图标着色

- 保留 `icons/deepseek.ico` 作为形状源，读取其中多尺寸 PNG 帧。
- 运行时按目标色（白 `#FFFFFF` / 黑 `#000000`）重新着色：保留 alpha，替换 RGB，编码为
  PNG 后组装 PNG-compressed ICO，缓存到安装目录（如 `auto-dark.ico` / `auto-light.ico`）。
- 备选 A：预生成两套静态 ICO——简单但颜色写死，不选。
- 备选 B：SVG 渲染——需要额外依赖，不选。

### 主题检测

- 读 `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\SystemUsesLightTheme`
  （1 = 浅色任务栏，0 = 深色）。
- 每 3 秒的现有 tick 里顺带比对一次值（开销可忽略），变化时重建/切换图标，不重启托盘。
- 不采用 RegistryKey 事件（PowerShell 对 .NET 注册表事件支持差）。

### 菜单

- Add-Type 定义 C# 自定义 `ToolStripRenderer`：深/浅两套配色（背景、文字、悬停、分隔线），
  悬停高亮用品牌蓝 `#4D6BFE`。
- 菜单项配 16×16 图标（打开界面/日志/重启/退出），统一字号与内边距。
- 结构：打开界面、打开日志 ─ 图标（自动适配主题 / 自定义…）─ 开机自启 ─ 重启 Harness、退出。

### 顺带修复

- 默认图标改为「自动适配」；快捷方式图标跟随当前主题图标。
- 切换图标不再弹气泡；自定义图标不再被自动覆盖，但选预设时更新快捷方式。
- config 中图标以语义值保存（`auto` / 自定义绝对路径），并在读取时校验存在性。
- `package.json` files、README、install.ps1 同步去掉梁祖/鲸鱼娘相关资源与默认值。

## 留给实现者的决定

- 缓存文件名、ICO 尺寸集合、菜单精确像素间距可自行决定。
- 品牌蓝的具体取值若在深浅主题下对比不足，可调整（默认 #4D6BFE）。
